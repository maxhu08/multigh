Details:
    With no subcommand, list this repo's allowed identities. add permits an
    existing global identity, preserving other selections; remove revokes one
    permission. Names are case insensitive and repeated additions do not
    duplicate entries. Removing the final permission leaves the repo blocked.

    update takes no arguments and opens a checklist. Use arrows to move,
    Space to select/deselect, Enter to save at least one identity, or Esc/Ctrl+C
    to cancel. Current selections start checked. Forms need terminal input,
    stdout and stderr. These commands do not switch gh login.

Examples:
    mgh repo allowed
    mgh repo allowed add personal
    mgh repo allowed add school
    mgh repo allowed add work
    mgh repo allowed remove school
    mgh repo allowed update
