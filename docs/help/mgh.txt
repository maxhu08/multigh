Getting started:
    Run mgh setup to create your first identity and install Git hooks.
    Add more with mgh identity new. Inside a repo, run mgh repo allowed update
    to choose permissions, then mgh switch <identity>. Run mgh doctor for issues.

    An identity is a configured identity name such as personal, school or work,
    mapped to a GitHub account and commit details. Personal, PERSONAL and personal
    are equivalent. Identity and settings commands are global; repo commands
    affect only the current Git repository. Repo protections default ON.

Configuration:
    --config selects another JSON or JSONC file. The default is
    ~/.config/multigh/identities.jsonc, or XDG_CONFIG_HOME/multigh/identities.jsonc.
    Identity files, hooks and global preferences use XDG_STATE_HOME/multigh,
    defaulting to ~/.local/state/multigh. Repo permissions and protections are
    local Git configuration; autoswitch is global under mgh settings.
    Load mgh shell init <shell> for entry/startup behavior.
