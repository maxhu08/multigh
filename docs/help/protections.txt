Details:
    Show or toggle protections only for this repo. Default ON when no local
    preference is saved. off saves an explicit exception; on restores enforcement
    and installs or repairs shared hooks. Setup preserves explicit OFF.
    With protections on, commits and pushes require an allowed gh account and
    matching commit details. An empty allowed list blocks both operations.
    Existing project hooks continue running when mgh protections are off.
    Local Git hooks can be bypassed by clients that do not run them.

Examples:
    mgh repo protections
    mgh repo protections off
    mgh repo protections on
