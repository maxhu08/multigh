Details:
    Show global preferences with no subcommand. autoswitch selects an allowed
    identity on repo entry/startup; verbose controls allowed-identity
    and detected-hook entry reports; welcome controls the terminal greeting.
    Toggle each independently with on/off; omit state to show its preference.
    These settings preserve repo protections. Enabling autoswitch also runs
    entry checks in the current repo and may prompt you to choose permissions
    if none are configured; permissions change only when you save a selection.

Examples:
    mgh settings
    mgh settings autoswitch on
    mgh settings verbose off
    mgh settings welcome on
