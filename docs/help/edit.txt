Details:
    Change a global identity's username, commit name or email. Without flags,
    prompt with existing values as defaults using cliclack. Supplied flags edit
    only those fields. Preserve other identities, JSONC comments, formatting and
    additional emails. Validate before saving; verify GitHub login for the chosen
    username. Cancelled input, invalid values and failed login do not save.
    Refresh generated identity rules without expanding any repo's permissions
    or switching its account. Run mgh switch <identity> to apply local details.

Examples:
    mgh identity edit personal
    mgh identity edit work --email work@example.com
