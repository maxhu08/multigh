Details:
    Add a global case-insensitive identity. Prompt for missing identity name,
    GitHub username, commit name and commit email. Commit name
    defaults to the username. Noninteractive use requires identity, --username
    and --email. Esc or Ctrl+C cancels without saving. Existing comments and
    formatting are preserved; symlinks require --config with their target.

    Reuse an existing successful gh login, or open browser authentication and
    verify the requested username. Save privately and atomically, refresh setup
    and select the identity. Failed authentication or concurrent config edits
    preserve the original config. If refresh/switch fails after saving, report
    recovery instructions. Repository permissions remain unchanged; use
    mgh repo allowed add <identity> separately.

Examples:
    mgh identity new
    mgh identity new work --username work-login --email work@example.com
