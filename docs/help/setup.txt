Details:
    Read your existing account file and generate identity files and global
    include rules for repositories owned by configured GitHub accounts over HTTPS
    or standard SSH URLs. Group Accounts, global Git config and Identity filepaths
    at the top, with the global updated/unchanged notice before mode explanations.
    The global filepath comes from Git and respects custom and XDG locations.
    New or changed global entries and identity files include a generated-by
    comment naming mgh setup. Report global changes once; matching entries stay
    untouched.
    If successful without global changes, print Global Git config unchanged.

    Install shared Git hooks, chain any repo-specific hook path in the current
    repo, and turn BOTH protections and verbose ON, explaining
    each. Protections ask for allowed accounts and block other accounts' commits
    and pushes. Verbose shows allowed accounts on repository entry and startup.
    Load mgh init <shell> in your shell config for entry and startup behavior.

    Create accounts.conf with mgh new or from example/accounts.conf first. Setup
    preserves that file; run it again after editing. State uses ~/.local/state/multigh or
    XDG_STATE_HOME/multigh. Conflicting global identity rules or a custom global
    hooks path are reported; they are not silently replaced.
    Requires Git 2.45 or newer for generated config comments.

Examples:
    mgh setup
    mgh --config /path/to/accounts.conf setup
