Details:
    Validate live gh authentication against this repository's allowed
    identities, then check actual author and committer names and emails for that
    identity. Author and committer overrides from Git options and environment
    are included.

    Success is silent; mismatches and unconfigured repos exit with an error.
    Outside a repository, no check is performed. This manual command checks even
    when protections are off. Outgoing history is checked by the push hook.

Examples:
    mgh check
    mgh --config /path/to/identities.jsonc check
