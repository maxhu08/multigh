Details:
    Select a case-insensitive global identity, switch gh authentication and update
    global commit defaults. Inside a repo that allows the identity, also update
    local commit details. Permissions remain unchanged; use repo allowed add
    separately. Global changes are reported and annotated with this command.
    The active gh account is shared across terminals.

    Invalid or conflicting repository permissions stop switching before
    authentication or settings change. Correct the reported repository identity
    settings before retrying.

Examples:
    mgh switch personal
    mgh repo allowed add work
    mgh switch work
