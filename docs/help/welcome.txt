Details:
    With no argument, show a purple Identity label and green identity name in
    the second column without a separator, aligned with the GitHub username and
    effective commit email below. Colors require a capable terminal and respect
    NO_COLOR. When welcome is disabled, print nothing. on and off save the preference
    without switching identities.

    Add mgh welcome to your shell's startup greeting to display it
    automatically. It maps the locally selected GitHub account to an identity
    for fast startup; use mgh status for live authentication information. The
    preference is stored outside the repo.

Examples:
    mgh welcome on
    mgh welcome
    mgh welcome off
