Details:
    Toggle switching globally for every repo; default OFF. With no state, show
    the global preference. on also checks the current repo when inside one. Shell
    integration applies it on repo entry and interactive terminal startup.
    One allowed identity is selected automatically unless already active.
    With multiple allowed identities, choose one using arrows and Enter;
    Esc/Ctrl+C cancels without switching. Only allowed identities are shown.

    Switching changes gh authentication, global commit defaults and this repo's
    commit details, like mgh switch. Permissions stay unchanged. An empty allowed
    list is not switched; protections may prompt for permissions first. Without
    a terminal, multiple choices print guidance. Switching failures are reported
    without breaking shell startup. Commit/push hooks never switch accounts.

Examples:
    mgh settings autoswitch on
    mgh settings autoswitch off
    mgh settings autoswitch
