Details:
    Select an existing gh login, update global Git user.name and user.email,
    and refresh identity rules for repositories owned by configured accounts.
    Sign in with gh auth login first, or use mgh new to add and select an account.
    Account aliases are case insensitive.
    New or changed global settings and generated identity files carry a comment
    naming this switch command. Report global changes once; matching global values
    and their existing comments stay untouched. Requires Git 2.45 or newer.
    If successful without global changes, print Global Git config unchanged.

    If this account is allowed in the current repo, also update its local commit
    identity. --repo explicitly adds the account to this repo's allowed list and
    selects its identity. Other repos retain their local identities.
    This does not enable protections; use setup or protections on to do that.

Examples:
    mgh switch personal
    mgh switch school
    mgh switch work
    mgh switch personal --repo
