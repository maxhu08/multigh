Details:
    Read your existing identity configuration and generate identity files and
    global include rules for repositories owned by configured GitHub accounts
    over HTTPS or standard SSH URLs. Group Accounts, global Git config and
    Identity filepaths at the top, with the global updated/unchanged notice
    before mode explanations. The global filepath comes from Git and respects
    custom and XDG locations. New or changed global entries and identity files
    include a generated-by comment naming mgh setup. Report global changes once;
    matching entries stay untouched. If successful without global changes, print
    Global Git config unchanged.

    Install shared Git hooks, chain any repo-specific hook path in the current
    repo, and turn BOTH protections and verbose ON, explaining each. Protections
    ask for allowed identities and block other identities' commits and pushes.
    Verbose shows allowed identities on repository entry and startup. Load mgh
    init <shell> in your shell config for entry and startup behavior.

    Create identities.jsonc with mgh new or from examples/identities.jsonc first. Setup
    preserves that file; run it again after editing. State uses
    ~/.local/state/multigh or XDG_STATE_HOME/multigh. Conflicting global
    identity rules or a custom global hooks path are reported; they are not
    silently replaced. Requires Git 2.45 or newer for generated config comments.

Examples:
    mgh setup
    mgh --config /path/to/identities.jsonc setup
